# wsignal: поиск слабых технологических сигналов

Сервис автоматизированного сбора и анализа зарождающихся технологических трендов по открытым источникам
(задача Газпромбанк.Тех, «Лидеры цифровой трансформации» 2026).

На вход подаётся свободный запрос по технологическому направлению («слабые сигналы в энергетике»,
«безопасность ИИ-агентов»). На выходе получается ранжированный список технологий, которые пересекают порог прямо сейчас.
Для каждой приводятся оценки реальности, динамики и незаметности, обоснование, кейс-пример,
дословно проверенные цитаты из источников и итог попытки её опровергнуть. Зрелые технологии и шум
не выбрасываются молча: они показаны отдельным списком с причиной исключения.

Ничего не берётся из «памяти» модели: каждое утверждение в отчёте опирается на скачанный и сохранённый
документ, а цитата сверяется с его текстом.

## Запуск

Для установки нужен Docker Engine 24+ с Compose v2. Python, Node, база данных и зависимости живут внутри
контейнеров.

```bash
git clone https://github.com/whatanaiceguy/wsignal
cd wsignal
docker compose up --build
```

Откройте <http://localhost:8000>.

Настраивать ничего не нужно: без файла `.env` вызовы языковых моделей, платный веб-поиск и
исследовательский корпус идут через сервер проекта `api.1f608.com`. Команда собирает образ,
поднимает PostgreSQL, применяет миграции и запускает API вместе с веб-интерфейсом на одном порту.
Первая сборка занимает несколько минут.

Проверка:

```bash
curl http://localhost:8000/health
```

```json
{"status":"ok","database":"ok","routes":{"llm":"relay","corpus":"relay","brave":"relay","epo":"off","rospatent":"off","x":"off"}, ...}
```

`routes` показывает, куда идёт каждый внешний сервис (ключи там не показываются никогда). То же
сервис пишет в лог при старте: `docker compose logs api | grep route`.

Остановка:

```bash
docker compose down        # данные сохраняются
docker compose down -v     # вместе с базой данных
```

Порт меняется переменной `API_PORT` (например, `API_PORT=8001 docker compose up --build`).

### Свои ключи и сервер проекта

Ключи не хранятся в репозитории. Каждый внешний сервис вызывается напрямую, если для него задан
свой ключ, и через сервер проекта, если ключа нет. Скопируйте `.env.example` в `.env` и заполните нужное.

| Сервис | Переменная | Без ключа |
|---|---|---|
| Языковые модели (OpenRouter) | `OPENROUTER_API_KEY` | через сервер проекта |
| Исследовательский корпус | `CORPUS_URL` (свой сервер корпуса) | через сервер проекта |
| Веб-поиск Brave | `BRAVE_API_KEY` | через сервер проекта |
| Патенты EPO | `EPO_CONSUMER_KEY`, `EPO_CONSUMER_SECRET_KEY` | отключено |
| Патенты Роспатента | `SEARCHPLATFORM_ROSPATENT_API` | отключено |
| X (Twitter) | `X_BEARER_TOKEN` | отключено |

Бесплатные источники (OpenAlex, arXiv, Hacker News, DuckDuckGo, загрузка страниц) всегда работают
напрямую. Отключённый источник не ломает исследование: агент получает явный ответ «ключа нет» и
использует остальные.

Режим задаётся переменной `WSIGNAL_MODE`:

- `auto` (по умолчанию): свой ключ напрямую, иначе сервер проекта;
- `local`: сервер проекта не используется никогда, сервис без ключа отключается;
- `relay`: всё, что обслуживает сервер проекта, идёт через него даже при наличии ключа.

Для отдельного сервиса маршрут задаёт `WSIGNAL_ROUTE_<СЕРВИС>=direct|relay` (`LLM`, `CORPUS`, `BRAVE`, `EPO`, `ROSPATENT`,
`X`). Порядок решения: явный маршрут сервиса, затем режим, затем наличие ключа.

Сервер проекта обслуживает только модели из конфигурации сервиса и держит суточный бюджет на
адрес; для интенсивной работы задайте свой `OPENROUTER_API_KEY`. Тексты статей корпуса выдаются по одной
статье на запрос, так же как их читают агенты.

## Как пользоваться

### Главная: история и новое исследование

Справа находится панель **«Новое исследование»**. Введите направление или технологию свободным текстом
(или выберите пример под полем) и нажмите **«▶ Запустить исследование»** (или Ctrl+Enter).

- **Глубина**: сколько технологий берётся в исследование (до 4, 7, 15 или 30).
- **Бюджет**: потолок расхода на вызовы моделей; при достижении исследование останавливается и его
  можно продолжить.
- **В отчёте**: ТОП-15 или все записи.

Исследование занимает от 10 до 40 минут. Вкладку можно закрыть: исследование продолжится на сервере и появится
в истории. Одновременно идёт одно исследование.

Слева находится **«История исследований»**: запрос, состояние, длительность, число записей и цитат,
стоимость. Щелчок по строке открывает отчёт (или ход работы, если исследование ещё идёт).

### Ход работы

Хроника исследования в реальном времени: как оркестратор делит направление, какие исследователи и
критики работают, что сдано и записано в отчёт. Хронику можно перемотать назад, а
завершённое исследование ещё и воспроизвести быстрее реального времени («▶ Запись исследования», ×10 …
×120). Кнопки **«■ Остановить»** и **«↻ Продолжить»** (с добавкой бюджета) работают и
здесь, и в отчёте: продолженное исследование не повторяет уже сделанную работу.

### Отчёт

Под заголовком расположена свёрнутая строка **«Поисковый запрос»**. Раскройте её, чтобы увидеть:

- модели, использованные в этом исследовании, по ролям;
- статистику: сколько кандидатов найдено (ссылка «→ список» ведёт к таблице), сколько
  вероятных сигналов (≥ 0,5) и сигналов с уверенностью выше 75%, сколько цитат подтверждено,
  сколько источников обработано, число агентов, длительность и стоимость.

Таблица **«Слабые сигналы»** отсортирована по силе слабого сигнала:

| Колонка | Что означает |
|---|---|
| Класс | слабый сигнал / сильный сигнал (зрелая технология) / шум |
| Слабость | итоговая оценка слабого сигнала, 0–1 (формула в [методологии](documentation/METHODOLOGY.md)) |
| Увер. | уверенность в том, что за утверждением стоит реальная растущая активность |
| Р / Д / Н | реальность, динамика, незаметность; наведите курсор, чтобы увидеть значения |
| Цитаты | дословно подтверждённые / всего |
| Корпус | помесячная доля упоминаний в отраслевой прессе за 3 года |

Ниже идёт свёрнутый список **«Исключённые кандидаты»**: зрелые технологии и неподтвердившиеся
утверждения, каждый с причиной исключения.

Щелчок по строке открывает подробности под таблицей.

- **Доказательства**: карточки источников с названием и ссылкой, датой публикации, типом
  (статья, новость, патент, стандарт, репозиторий …), языком оригинала и уровнем доверия
  (первоисточник, отраслевой, соцсеть, не определён). Цитата приведена на языке оригинала и
  отмечена «✓ проверена», если найдена в сохранённом тексте страницы. У каждого
  источника, в том числе иностранного, есть русское резюме с пометкой «резюме сгенерировано
  автоматически»; в шапке отчёта и записи стоит общая пометка «сгенерировано моделями».
- **Оппонент против исследователя**: каждая попытка опровержения, её итог (критика подтверждена /
  подтверждена частично / не подтверждена) и ответ исследователя.
- Панель записи со сворачиваемыми разделами: **«Почему это слабый сигнал»** (или «Почему
  исключено»), **«Технология»** (описание, проблема, преимущество, кейс-пример),
  **«Динамика»**, **«Ключевые предикторы»** (сработавшие признаки с силой и цитатой),
  **«Что опровергло бы вывод»**.
- **Корпус · помесячные упоминания**: число статей и доля на 10 тыс. статей месяца. Запрос
  к корпусу можно изменить прямо в панели; слишком общий запрос помечается предупреждением.

**«Открыть как документ →»** показывает запись как отдельный документ-отчёт (технология,
преимущества, кейсы, оценки, источники) с кнопкой **«Печать / PDF»**; печать всегда в светлой
теме.

### Инспекция

`/dev` содержит технические страницы для разбора исследования: все агенты, их ходы и промпты, вызовы
инструментов, источники и ошибки (вкладка «Ошибки»). Интерактивная документация API открывается по адресу
<http://localhost:8000/docs>.

## Модели

Модель задаётся на роль; автоматического выбора модели нет:

| Роль | Модель по умолчанию |
|---|---|
| оркестратор, ассистент | `z-ai/glm-5.3-flash` |
| исследователь, критик, экстрактор | `openai/gpt-6-luna` |

Изменить можно переменными `WSIGNAL_LLM_MODEL_<РОЛЬ>`. Модели каждого исследования перечислены в
отчёте, а каждый вызов сохраняется в базе с моделью, провайдером, идентификатором генерации,
токенами и стоимостью (страницы `/dev`).

## Структура репозитория

Логика сбора, инференса и интерфейса разделена по пакетам (ТЗ §3.2).

```
src/wsignal/
  parsing/     адаптеры источников, HTTP-транспорт с лимитами, извлечение текста, уровни доверия
  inference/   агенты, оркестрация, проверка цитат, скоринг, учёт вызовов
  interface/   HTTP API, фоновые исследования, поток событий, сборка отчёта
  corpus.py    клиент исследовательского корпуса
  routes.py    маршрутизация внешних сервисов: свой ключ / сервер проекта / выключено
  models.py    схема данных (PostgreSQL)
  config.py    все настройки (переменные WSIGNAL_*)
prompts/       промпты ролей
web/           веб-интерфейс (React)
migrations/    миграции Alembic
tests/         тесты
documentation/ методология, пайплайн, схема архитектуры
```

Зависимости: `pyproject.toml` и `uv.lock` (Python), `web/package.json` и `web/pnpm-lock.yaml`
(интерфейс).

## Разработка

Режим разработки монтирует `src/` в контейнер, включает автоперезагрузку и публикует базу на
порту 55432:

```bash
docker compose -f docker-compose.yml -f docker-compose.dev.yml up --build
cd web && pnpm install && pnpm dev     # интерфейс с горячей перезагрузкой на :5180
```

Тесты и линтер (нужен [uv](https://docs.astral.sh/uv/)):

```bash
uv sync
uv run pytest
uv run ruff check .
```

Скрипты-обёртки для Linux, macOS и WSL лежат в `scripts/` (`up.sh`, `down.sh`, `logs.sh`, `test.sh`,
`psql.sh`, `migrate.sh`); на Windows те же действия вызываются через `python dev.py <действие>`.
Скрипты из `scripts/` и `python dev.py` требуют WSL (без него `dev.py` завершается с ошибкой).
На Windows без WSL достаточно установить Docker Desktop и выполнить ту же команду `docker compose up --build`
из PowerShell: `.gitattributes` сохраняет LF в файлах контейнера, а образ не запускает
shell-скриптов. Этот путь на Windows пока не проверялся.

Запуск из консоли без интерфейса:

```bash
python dev.py ask "слабые сигналы в области защиты ИИ"
python dev.py report 1          # отчёт исследования в консоли
```
